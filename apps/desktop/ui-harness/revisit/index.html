Evidence and limits

Native captures use the current Mac frontend in an offscreen WKWebView, with synthetic command responses. They are not captures of your installed Yawn or real meetings. Related-state frames pose the correspondence cue for visual review; browser checks exercise the actual hover and keyboard behavior.

The interactive view uses the same frontend and synthetic meetings. Switching scenes resets the sample. Audio capture, playback delivery, backend storage and release packaging are outside this comparison. The rail remains a visual guide; this study adds no audio-seeking control.
