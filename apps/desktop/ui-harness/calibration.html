Packet W9-A calibration sheet. Dev tool, not shipped UI — opened directly in a browser (open apps/desktop/ui-harness/calibration.html from the repo root; no server needed since it only loads a same-directory stylesheet). Three typography treatments of the same fixture note and transcript, each rendered in both themes so the operator can judge without an OS dark-mode toggle. Content is the exact synthetic fixture at crates/session-core/src/bin/fixtures/note-meeting/ (note.md + source-turns.json) — never lorem, never a real meeting. Changing a treatment here changes nothing in ui/styles.css; each column only overrides --measure-reading, --leading-reading, --leading-transcript, --text-note-summary, --text-note-item, and --text-transcript-body on itself.
