# Marquee Document — Quiet

This preserves Marquee Document's full-bleed reading surface and decisive
object hierarchy. It reduces the title scale, widens its useful line length,
and returns section headings to sentence case so the note no longer resembles
an editorial publishing system.

The supporting chrome still recedes. Violet is reserved for selection,
evidence, focus, and the sparse-state insertion rail. Operator notes use only
top and bottom rules, keeping them writable without placing another card inside
the document.

The question it tests: can Marquee's hierarchy feel personal and durable once
its loudest gestures are removed?
