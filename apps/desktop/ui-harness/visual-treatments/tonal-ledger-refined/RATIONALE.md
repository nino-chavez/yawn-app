# Tonal Ledger — Canvas

This keeps Tonal Ledger's low-chroma violet and contained reading experience,
but removes the tall rounded document card. The center pane becomes the reading
surface. A narrower content column supplies focus without making Yawn look like
a card placed inside a window.

The title remains decisive but uses the system type voice. Operator notes keep
a lightly bounded material because they are an editable object, while generated
content stays directly on the canvas. Selection, evidence, and recovery retain
their semantic colors.

The question it tests: can the pane itself create privacy and focus, or does
Yawn need a visible document object?
